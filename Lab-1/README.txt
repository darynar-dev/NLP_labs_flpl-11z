Лабораторна робота № 1 з дисципліни «Комп'ютерна лінгвістика»
Виконала: Руденко Д. С., група ФЛПЛ-11з

Структура файлів:
- text.txt — вхідний україномовний текст (кодування UTF-8)
- Блок 1.py — базова токенізація тексту на речення і слова засобами NLTK та збереження результатів у файли
- Блок 2.py — препроцесинг, наївна сегментація, морфосинтаксичний аналіз і частотний розподіл POS (Stanza), а також порівняння токенізації, сегментації та лематизації (NLTK, Stanza, spaCy)
- sentences.txt — результат поділу на речення (генерується після запуску Блок 1.py)
- words.txt — результат поділу на токени (генерується після запуску Блок 1.py)

Встановлення залежностей перед запуском (Python 3.10+):
pip install nltk spacy stanza
python -m spacy download uk_core_news_sm
python -c "import stanza; stanza.download('uk')"

(Ресурси NLTK 'punkt' та 'punkt_tab' завантажуються автоматично під час запуску скриптів.)

Запуск скриптів:
python "Блок 1.py"
python "Блок 2.py"
