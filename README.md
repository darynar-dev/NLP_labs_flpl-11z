# Практикум із комп'ютерної лінгвістики (NLP)

Навчальний репозиторій із лабораторними роботами з дисципліни «Комп'ютерна лінгвістика» (спеціальність 035.10 «Прикладна лінгвістика», НУ «Львівська політехніка»).

У проєкті зібрано практичні завдання з обробки українськомовних текстів за допомогою Python та інструментів NLP.

## Структура проєкту

```text
NLP_labs_flpl-11z/
├── Lab-1/               # Токенізація та морфологічний аналіз
├── Lab-2/               # Регулярні вирази
├── Lab-3/               # Синтаксичний аналіз і корпусна статистика
├── Lab-4/               # Векторні представлення та трансформери
├── .gitignore
├── requirements.txt
└── README.md
```

## Технології

- Python 3.13
- NLTK
- spaCy
- Stanza
- Regular Expressions (`re`)
- Gensim / FastText
- Hugging Face Transformers
- PyTorch

## Встановлення залежностей

```bash
pip install -r requirements.txt
```
